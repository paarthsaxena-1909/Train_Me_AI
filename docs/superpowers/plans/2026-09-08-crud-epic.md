# Train Me CRUD Epic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a role-aware Train Me CRUD application with authentication, product management, mock-generated assignments, mock product Q&A, and daily face attendance.

**Architecture:** Complete one dependency-ordered vertical slice before the next. Backend requests follow controller → service → repository → SQL, while cross-domain work goes only through typed ports in `backend/app/orchestration/`; frontend server state uses TanStack Query and authentication state uses Redux.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, PyJWT, pwdlib/Argon2, asyncpg, SQLAlchemy/Alembic, PostgreSQL 16, React 19, TypeScript, React Router, Redux Toolkit, TanStack Query, Tailwind CSS, Vitest, Testing Library, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-08-crud-epic-design.md`

## Global Constraints

- Deliver slices in this order: foundation, authentication, products, assignments, Q&A, face attendance, final integration.
- Services never call another domain service directly. Cross-domain workflows use typed ports and mediators under `backend/app/orchestration/`.
- Runtime database work uses one readable SQL file per operation under `backend/app/queries/postgres/<domain>/`; do not use ORM query APIs.
- Services own transactions; repositories do not create sessions or commit.
- All controllers use `/api/v1`, explicit Pydantic request/response models, and role dependencies.
- Passwords use Argon2 hashes. JWTs are expiring bearer tokens; protected calls also confirm the account remains active.
- Agent pincode is a six-character geographic string and preserves leading zeroes.
- Product hierarchy is lineup → product → variant. Variants use generated IDs and text `specs`; there is no SKU.
- One face image is accepted per agent per `Asia/Kolkata` calendar day; a second returns HTTP 409.
- Assignment generation/evaluation, Q&A answers, and face analysis are deterministic mocks whose stored/UI copy says AI integration is pending.
- Mock providers accept extensible context objects with `additional_sources`, and concrete mocks are injected behind protocols.
- Uploaded media lives under `/data/uploads` through a storage protocol backed by a named Docker volume.
- Frontend work follows `frontend/.agents/skills/train-me-brand-identity/SKILL.md` and existing semantic Tailwind colors.
- Each feature includes Markdown service documentation and a Mermaid sequence diagram with `IMPLEMENTED` and `PENDING AI REPLACEMENT` labels.
- Preserve unrelated work and do not edit `prototype/`.
